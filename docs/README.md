# Py-Music Studio

The `docs/` directory is the static GitHub Pages application for Py-Music.

## Browser DAW roadmap

The web application is designed as a zero-install music workstation:

- piano and computer keyboard input
- scales, modes and chord construction
- multi-track sequencing
- piano-roll editing
- drum and bass tracks
- Web Audio synthesis
- WAV rendering
- MIDI import/export
- project JSON import/export
- local project persistence
- transport and metronome
- waveform/spectrum visualization
- effects and automation

The application does not require Python, a server or a database to run in the browser.

The Python package in the repository remains the full native development engine.
