Features

Music Theory

Scales, modes, chords, intervals, transposition, frequencies, MIDI mapping, and harmonic calculations.

Composition

Deterministic procedural melody, rhythm, chord and song generation with reproducible seeds.

MIDI

Import and export musical events with timing, velocity, channel, and track information.

Synthesis

Dependency-light waveform rendering with oscillators, envelopes, velocity and multitrack mixing.

Persistence

SQLite-backed song storage and serialization for projects, tracks, notes and metadata.

Plugins

An extensible plugin host for composition transforms, instruments, effects and future integrations.

Quick start

pip install -e .
python -m pymusic.cli generate --title "Aurora" --key D --scale dorian --bars 16

Project direction

Py-Music is designed to grow from a Python music toolkit into a complete programmable music workstation with piano-roll editing, real-time MIDI, DSP effects, visualization, project files, instrument libraries, and a desktop interface.
