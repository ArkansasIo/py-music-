What runs here?

The GitHub Pages build is a static application. It does not require a server, Python runtime or database to use the interactive studio.

Project files

Projects are stored in your browser with localStorage or exported as portable JSON. Audio is rendered locally and downloaded as a WAV file.

Python engine

The repository also contains the full Python theory, composer, MIDI, audio, database, plugin and API modules for native development.
